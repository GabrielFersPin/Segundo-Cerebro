## 📝 Captura principal

> [!tip] Lo más importante
> es el protocolo que permite solicitar y transferir recursos entre un cliente, como un navegador, y un servidor.


### 🎯 Detalles / Contenido

<!-- Captura rápida del contenido sin preocuparte por formato perfecto -->

Por ejemplo, cuando visitas una página web:

1. El navegador envía una solicitud HTTP al servidor.
2. El servidor procesa la solicitud.
3. El servidor devuelve una respuesta HTTP, como una página HTML, una imagen o datos JSON.

| Verbo HTTP | Definición | Acción |
|---|---|---|
| `GET` | Solicita información de un recurso. | Obtener datos de un servidor. |
| `POST` | Envía información para crear un recurso o procesar una acción. | Crear o enviar datos. |
| `PUT` | Reemplaza completamente un recurso existente. | Actualizar todo el recurso. |
| `PATCH` | Modifica parcialmente un recurso. | Actualizar solo algunos campos. |
| `DELETE` | Solicita la eliminación de un recurso. | Borrar datos. |
| `HEAD` | Solicita solo las cabeceras de una respuesta, sin el contenido. | Comprobar información del recurso. |
| `OPTIONS` | Indica qué métodos y opciones admite un servidor. | Consultar las capacidades disponibles. |
| `CONNECT` | Establece un túnel de comunicación con el servidor. | Crear una conexión directa, normalmente mediante un proxy. |
| `TRACE` | Devuelve la solicitud recibida para comprobar la comunicación. | Diagnosticar la ruta de una solicitud. |
Los más comunes son GET, POST, PUT y DELETE
