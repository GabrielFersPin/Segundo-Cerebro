## 📝 Captura principal

> [!tip] Lo más importante
>Amazon DynamoDB es una base de datos NoSQL administrada y sin servidor de AWS, diseñada para aplicaciones que necesitan baja latencia y alta disponibilidad a gran escala.



### 🎯 Detalles / Contenido


- Guarda datos en tablas con elementos y atributos.
- Usa una clave primaria para identificar cada elemento.
- Escala automáticamente en capacidad y rendimiento.
- Ofrece lecturas y escrituras rápidas, replicación y copias de seguridad.
- Admite modelos de capacidad bajo demanda o aprovisionada.
- Es útil para aplicaciones web y móviles, IoT, videojuegos, carritos de compra y sistemas en tiempo real.
- No utiliza SQL tradicional como una base de datos relacional; el diseño de las claves y los patrones de consulta es fundamental.

En resumen: DynamoDB prioriza escalabilidad, disponibilidad y velocidad, a cambio de requerir más planificación en el modelado de datos.
