## 📝 Captura principal

> [!tip] Lo más importante
> Amazon EFS (Elastic File System) es un sistema de archivos administrado y elástico en AWS.


### 🎯 Detalles / Contenido

<!-- Captura rápida del contenido sin preocuparte por formato perfecto -->

- Permite compartir archivos entre varias instancias EC2 y otros servicios como ECS o Lambda.
- Se accede normalmente mediante NFS.
- Aumenta o reduce automáticamente su capacidad según los datos almacenados.
- Está diseñado para alta disponibilidad dentro de una región.
- Es útil para directorios compartidos, contenido web, procesamiento de archivos y aplicaciones que necesitan almacenamiento común.

Comparación rápida:

- [[Amazon EFS]]: sistema de archivos compartido.
- [[Amazon EBS (Elastic Block Store)]]: disco virtual normalmente asociado a una instancia EC2.
- [[Amazon S3]]: almacenamiento de objetos para archivos y datos mediante API.
