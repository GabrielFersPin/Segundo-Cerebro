## 📝 Definición

AWS Glue es un servicio totalmente administrado de extracción, transformación y carga, o ETL, que facilita a los desarrolladores el preparar y mover datos para análisis.

---

## ⚙️ Conceptos Clave

## AWS Glue Data Catalog

- Almacena metadata de las fuentes de datos. El metadata incluye información acerca de la localización y esquemas, incluye tipos de datos y definiciones de tablas.

## AWS GLue crawler

- Puedes rellenar el catálogo de manera automática haciendo un escaneo de las fuentes de datos 

## AWS Glue Data Quality

- Evalúa objetos que están almacenados en el **AWS Data Catalog**.
- Herramienta no-code que ofrece una manera de implementar reglas para controlar la calidad de los datos.
- Utiliza machine learning para detección de anomalías.
- Después de implementar las reglas puedes revisar los resultados en la consola para determinar que reglas pasan y las que no.
