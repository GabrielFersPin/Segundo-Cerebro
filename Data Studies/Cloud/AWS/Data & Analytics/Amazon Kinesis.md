## 📝 Captura principal

> [!tip] Lo más importante
> Amazon Kinesis es un conjunto de servicios de AWS para recopilar, procesar y analizar datos en tiempo real o con muy poca latencia.


### 🎯 Detalles / Contenido

<!-- Captura rápida del contenido sin preocuparte por formato perfecto -->

Se utiliza para recibir continuamente eventos como:

- Logs de aplicaciones.
- Datos de sensores IoT.
- Clics de usuarios.
- Transacciones.
- Actividad de sitios web.

Sus servicios principales son:

- Kinesis Data Streams: captura y transporta flujos de datos para procesarlos posteriormente.
- Kinesis Data Firehose: entrega datos automáticamente a destinos como S3, Redshift, OpenSearch o Splunk.
- Managed Service for Apache Flink: procesa y analiza los datos en tiempo real.
- Kinesis Video Streams: ingiere y procesa vídeo en directo.

Ejemplo:

> Una aplicación genera eventos → Kinesis los recibe → Lambda o Flink los procesa → S3 guarda el histórico → Athena y QuickSight lo analizan.
