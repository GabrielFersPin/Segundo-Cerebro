## 📝 Captura principal

> [!tip] Lo más importante
> AWS CodeCommit es un servicio de AWS para alojar repositorios privados de código fuente, basado en Git.


### 🎯 Detalles / Contenido

Permite:

- Guardar y versionar código.
- Crear ramas (_branches_).
- Registrar cambios mediante commits.
- Revisar diferencias entre versiones.
- Trabajar con varios desarrolladores.
- Integrarse con CodePipeline para automatizar despliegues.

Ejemplo:

> Un desarrollador hace `push` a CodeCommit → CodePipeline detecta el cambio → CodeBuild ejecuta las pruebas → la aplicación se despliega.
