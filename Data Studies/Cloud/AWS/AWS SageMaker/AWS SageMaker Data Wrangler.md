### 🎯 Detalles / Contenido

- importar datos (por ejemplo desde S3 u otras fuentes),
- limpiar y tratar valores faltantes/duplicados,
- transformar variables (codificar, escalar, generar features),
- explorar datos (estadísticas/visualizaciones),
