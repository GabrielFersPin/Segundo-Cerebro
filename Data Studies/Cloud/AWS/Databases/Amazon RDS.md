## 📝 Captura principal

> [!tip] Lo más importante
> Amazon RDS sirve para alojar bases de datos relacionales gestionadas por AWS.


### 🎯 Detalles / Contenido

<!-- Captura rápida del contenido sin preocuparte por formato perfecto -->

En vez de administrar tú mismos el servidor de base de datos, RDS te da:

- el motor de base de datos (como MySQL, PostgreSQL, etc.),
- aprovisionamiento y gestión de la instancia,
- backups automáticos y restores,
- parches/mantenimiento (según configuración),
- y opciones de alta disponibilidad (por ejemplo réplicas).

En resumen: RDS es para tener una base de datos SQL en la nube sin tener que encargarte de toda la operación del servidor.
